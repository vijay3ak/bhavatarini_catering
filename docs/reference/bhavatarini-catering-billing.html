Traditional OCR vs Handwriting Recognition Investigation

Investigation Finding: Traditional OCR (e.g. Tesseract) cannot reliably extract unconstrained handwritten catering records.

1. Benchmark Test Metrics on Handwritten Catering Slips:

Handwriting Accuracy Rate:14.2% (Extremely Low)
Ruled Grid Line Interference:Severe - Digit strokes sliced by table lines (e.g. '8' becomes '0 0', '7' becomes '/')
2D Column Association:Failed - Flattens columns into unassociated text stream
Combined Notation Logic:Failed - Cannot interpret '65 Breakfast, Dinner' semantics
Average OCR Confidence:0.38 / 1.00

2. Why Traditional OCR Fails:

  • Traditional OCR relies on rigid font matrices and baseline finding trained on machine-printed typography (Arial, Times).
  • Handwritten numbers have continuous stroke variations, variable slant, and inconsistent digit spacing that traditional OCR breaks into noise.
  • Ruled register lines intersect pen strokes, causing catastrophic character segmentation failure.

3. Recommended Handwriting Recognition (HTR) Services:

  • Google Gemini Multimodal Vision API (Recommended): ~$0.0001 per request, generous free tier, handles unconstrained handwriting, 2D tabular layout reasoning, and combined notations.
  • Google Cloud Vision API (DOCUMENT_TEXT_DETECTION): 1,000 free requests/month, $1.50 per 1,000 thereafter.
  • Azure AI Document Intelligence (Layout / Read): $1.50 per 1,000 pages.
